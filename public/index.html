          Is this just ChatGPT with files?

          Not quite. The difference is not the files. It is who drives: in a chat, you do. In an agent, the model does.

          A chatbot

          1. You paste in or upload the documents.
          2. It writes back an answer.
          3. You check it, then ask for the next thing.

          You drive every step. One question, one answer, then it waits for you.

          Praxis, an agent

          1. You give it a goal. The files stay in a workspace it has to explore.
          2. It lists and opens the receipt files with tools.
          3. It writes a real spreadsheet, cell by cell.
          4. It can read its own work back and keep going.
          5. A separate script grades the actual file.

          Many steps, real tools, a checked result. Open the Every move it makes list after a run to see each step.

          The loop: decide the next step, use a tool, see what happened, repeat until the job is done or it runs out of steps (30 here).

          What happens when you press Run

          1. The agent gets one goal and a private copy of 24 receipts. It cannot leave that folder.
          2. The model decides what to do next and asks for a tool: list files, read a file, write cells.
          3. Praxis runs the tool and sends the result back. The model remembers nothing between turns, so everything it needs is sent again each time.
          4. This repeats until the agent says it is finished.
          5. A checker opens the real spreadsheet and tests 7 things against an answer key the agent never sees.
          6. If a check fails, Praxis points to what to change: context, tools or instructions.

          Plain-English glossary

          AI agent
          An AI that works toward a goal over many steps, using tools, instead of answering once like a chatbot.
          Company facts (context)
          Things the AI cannot guess, such as the euro rate.
          New ability (tool)
          Something it is allowed to do, such as adding a sheet.
          Instructions
          How you want the work done.
          Trajectory
          The step-by-step record of what it did. Read it to see where it went wrong.
          Feedback loop
          Run it, read the checks, change one thing, run again.

          Safety on this demo
